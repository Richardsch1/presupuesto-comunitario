# Contribuir

Usa ejemplos ficticios y no publiques datos de ciudadanos, claves ni archivos privados. Explica el problema, el comportamiento final y las pruebas realmente ejecutadas. Mantén las operaciones locales y evita dependencias de red innecesarias.

Requiere Node 22 o 24. Ejecuta `npm ci --ignore-scripts`, `npm run check` y `npm test`. Añade pruebas relevantes cuando cambien validaciones o cálculos. Las contribuciones se reciben bajo MIT.

Colabora con respeto: no se aceptan acoso, discriminación o divulgación de información privada. Solicita al mantenedor un canal privado sin publicar datos cuando sea necesario.
